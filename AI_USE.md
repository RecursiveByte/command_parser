# AI Use Documentation

## AI Tools Used
ChatGPT was used as an assistance tool during development.

## Usage
- Python code assistance and debugging.
- Unit test design.
- GitHub Actions workflow configuration.
- Model evaluation and JSON Schema validation guidance.

## Validation
AI-generated code was reviewed and validated using:
- Ruff linting.
- Python unit tests.
- JSON Schema validation.
- Model evaluation using data/validation.jsonl.
- Quality gate with a minimum validity threshold of 95%.

## Human Review
All generated code and configurations were reviewed and tested by the developer.
